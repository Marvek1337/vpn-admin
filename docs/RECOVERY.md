# Восстановление проекта

Исходная рабочая папка была утрачена. Код восстановлен из сохранённых в диалоге
чтений файлов и последовательности изменений за май–июнь 2026 года.
Сохранённые файлы восстановлены с последовательным применением правок;
в использованных фрагментах не осталось неизвестных строк или конфликтов контекста.

Восстановлены 74 файла: приложение FastAPI, модели, установщик, маршруты,
сервисы интеграций, шаблоны, CSS, Dockerfile и Compose.
Последние сохранённые изменения включают выдачу Amnezia WG на claim.

В истории не оказалось полного текста следующих небольших модулей. Они написаны
заново по контрактам сохранившегося приложения и проверены интеграционными тестами:

- `app/core/statuses.py` — состояния и типы заказов.
- `app/crud/configs.py`, `orders.py`, `payment_logs.py` — доступ к данным.
- `app/schemas.py` — ответы API.
- `app/scripts/check_integrity.py`, `import_wg_easy_clients.py` — обслуживание.
- Пустые файлы пакетов Python и favicon.

Заново добавлены README, тесты, CI, генератор окружения и исключения Git.
Устаревшие неиспользуемые стили и удалённая ранее интеграция Remnawave/VLESS
не включены в рабочий проект.

Брендинг заменён на `vpn-admin`. Жёстко заданный адрес callback бота вынесен в env.
Исправлена передача URL проверки задержки из установщика. Тестовые платежи требуют
явного включения и запрещены в production; callback отключённого провайдера отвергается.

Базы с пользователями, платёжные реквизиты, реальные секреты, приватные ключи и
серверные конфиги не восстанавливались в публичный репозиторий.
Отдельный Telegram-бот и код удалённых WG-Easy серверов в истории этого проекта
не обнаружены. Восстановленный сайт подключается к ним через существующие API.
