# vpn-admin

Панель продажи и выдачи WireGuard-доступов: личный кабинет, отдельные разделы
админки, GGSEL, Platega, Telegram, мониторинг свободных IP и импорт старой базы.
Настройка сервиса выполняется через мастер первого запуска `/install`.

## Запуск через Docker

Требуются Docker с Compose и Python 3 для создания файла окружения.

```bash
git clone https://github.com/Marvek1337/vpn-admin.git
cd vpn-admin
python3 scripts/init_env.py
docker compose up -d --build
```

Откройте `http://127.0.0.1:7005/install` и заполните администратора, тарифы,
серверы и необходимые интеграции. После установки мастер закрывается.
Данные сохраняются в Docker volume `vpn_data`. Команда `docker compose down -v`
удаляет этот volume вместе с базой, поэтому для обычного обновления её применять нельзя.

Для сервера настройте HTTPS reverse proxy на `127.0.0.1:7005`. В `.env`
укажите `APP_ENV=prod` и `PUBLIC_BASE_URL=https://ваш-домен`, а тот же публичный URL
сохраните в основных настройках админки. В production cookie требует HTTPS.
При необходимости удалённой первоначальной настройки используйте SSH-туннель:

```bash
ssh -L 7005:127.0.0.1:7005 user@server
```

После обновления исходников:

```bash
docker compose up -d --build --force-recreate
docker compose logs --tail=100 vpn-admin
```

Обычный `restart` не пересобирает Python-код и шаблоны.

## PyCharm и локальный запуск

Требуется Python 3.11 или 3.12. Откройте папку проекта, создайте интерпретатор
`.venv`, установите `requirements.txt` и запускайте `main.py` с рабочей папкой проекта.
Эквивалентные команды:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/init_env.py
python main.py
```

Локальная база создаётся в `data/app.db`. Реальных пользователей, конфигов,
приватных ключей, токенов и платёжных реквизитов в репозитории нет.

## Возможности

- Установка, авторизация, личный кабинет, заказы и продление доступов.
- Отдельные страницы серверов, мониторинга, пользователей, заказов и конфигов.
- Раздельные настройки GGSEL, Platega, Telegram, тарифов, товаров и юридических текстов.
- Выдача покупок GGSEL на `/claim?uniquecode=...`, файл и QR WireGuard.
- Отдельные файл и QR для Amnezia WG с заменой Endpoint по коду сервера.
- Привязка Telegram по коду и восстановление пароля через сообщения бота.
- Проверка доступных IP через WG-Easy `/api/client` и очистка просроченных клиентов.
- HTML-страницы ошибок для браузера, JSON-ответы для API.

Amnezia WG сохраняет исходные ключи и остальные параметры. Замена Endpoint сама
по себе не создаёт сервер AmneziaWG: принимающий сервер должен поддерживать эти
ключи и параметры. Таблица адресов находится в `app/services/amnezia_wg.py`.

Проверка задержки выполняется в браузере пользователя по публичному HTTP(S) URL,
который задаётся у сервера. Это задержка HTTP, а не ICMP ping. Для HTTPS-сайта
нужен HTTPS endpoint с валидным сертификатом, без авторизации и блокировки внешних ресурсов.

## Интеграции

GGSEL и Platega настраиваются в админке. Callback Platega:
`https://ваш-домен/payments/platega/callback`. Запрос должен содержать настроенные
`X-MerchantId` и `X-Secret`. Повторная обработка успешно применённого заказа
не выдаёт второй конфиг.

Тестовая оплата выключена по умолчанию. Для локальной разработки можно установить
`ALLOW_TEST_PAYMENTS=true`; в `APP_ENV=prod` она недоступна.
Для внешнего Telegram-бота опционально задаётся `BOT_PAYMENT_CALLBACK_URL`:
туда пересылаются проверенные callback с `payload`, начинающимся на `bot_`.
Исходники отдельного Telegram-бота в этом проекте отсутствуют.

## Импорт и обслуживание

Импорт старой SQLite-базы доступен в админке в разделе настроек импорта.
Путь должен существовать внутри контейнера. Например:

```bash
docker compose cp /путь/old_app.db vpn-admin:/tmp/old_app.db
```

В форме укажите `/tmp/old_app.db`. Импорт переносит пользователей и выданные
конфиги; серверы с соответствующими кодами добавьте в админке отдельно.
Для полного переноса текущей инсталляции переносите её volume с базой,
сохранив резервную копию перед заменой.

```bash
docker compose exec vpn-admin python -m app.scripts.check_integrity
docker compose exec vpn-admin python -m app.scripts.cleanup_expired_clients
docker compose exec vpn-admin python -m app.scripts.import_wg_easy_clients FI-2
```

Импорт клиентов WG-Easy по умолчанию только показывает количество новых записей;
для сохранения добавьте `--apply`. Очистку можно запускать по cron, например каждый час.
Период после истечения перед удалением задаётся в основных настройках.
Созданные через CLI конфиги не привязываются к аккаунтам автоматически.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m compileall -q app main.py scripts
```

Интеграционные проверки используют отдельную временную SQLite-базу и подменяют
внешние вызовы. Для реальной выдачи и оплаты нужны ваши работающие серверы и реквизиты.

восстановления описаны в [docs/RECOVERY.md](docs/RECOVERY.md).
