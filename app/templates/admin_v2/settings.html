Основные

Базовые данные продукта. Они используются в клиентском интерфейсе, документах и платежных ссылках.

Интеграции

GGSEL отвечает за проверку внешних покупок и управление активностью товаров. Platega используется для создания платежных ссылок в кабинете.

Telegram

Токен бота нужен для отправки кодов восстановления пароля. Имя бота используется в подсказках для привязки аккаунта.

Операции

Сервис показывает конфиги после окончания срока в течение grace-периода. Очистка удаляет клиента на WG-Easy только после этого буфера.

Импорт старой базы

Укажите путь к старому SQLite-файлу внутри сервера или Docker-контейнера. Импорт переносит пользователей и все записи из таблицы vpn_configs, дубли ищутся по unique_code + server_id.

Юридические страницы

Тексты публикуются на страницах “Политика конфиденциальности” и “Пользовательское соглашение”. Пишите готовый текст без HTML: каждый абзац с новой строки.

Добавить период
